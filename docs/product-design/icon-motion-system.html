mdbase icon motion system

Motion with a job.

The Frontmatter mark loops while work runs, plays an entrance when it first appears, reacts once when a write succeeds or fails, and fills with known progress. It never replaces status text.

Apps rarely set these directly. AppSwitcher reads the page-wide store in @mdbase-dev/ui/mark-activity, SaveNotice reports saves and problems to it, and apps call trackMdbaseMarkProgress, signalMdbaseMark or holdMdbaseMarkBusy for work that has no notice.
