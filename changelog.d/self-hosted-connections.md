## Added

- Pair a web app with a local Markdown collection using the guided Unix `mdbase pair-app` command. Use an invitation and separate single-use code for private online access, without a Connect account, proxy or relay, in a browser supporting certificate-pinned WebTransport. Each browser can be revoked independently. An explicit `mdbase self-host` gateway mode remains available for private HTTPS infrastructure.
- Add a separate `/direct` SDK entry for HTTPS browser pairing, optional remembered grants and the existing replica client. Editor can offer advanced users a link on its signed-out screen. If the server disconnects, Editor keeps unconfirmed text available to copy and reconnects on request.
