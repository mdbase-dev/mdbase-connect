## Added

- `@mdbase-dev/ui` has a `Switch` (`@mdbase-dev/ui/switch`) and a segmented control (`@mdbase-dev/ui/segmented`) for one choice among a few short options. `toast()` takes options in place of the undo function (`tone`, `sticky`, `durationMs`, `dismissible` and a custom `action`) and returns a function that dismisses the toast; success and error toasts carry a mark. New motion tokens `--ease-spring`, `--motion-spring` and `--motion-press` give controls a quick press and a springy release.
