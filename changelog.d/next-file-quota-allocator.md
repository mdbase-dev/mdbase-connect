## Added

- Add a default-off file quota allocator (`MDBASE_NEXT_FILE_QUOTA=report|enforce`) that shares each account's plan storage across its native collections. Every hour, and as soon as a collection is created, each collection gets its current file bytes plus everything the plan has left, so any one collection can take an upload the account has room for. Uploads to several collections within the hour can take the account past its plan once; the next pass then stops further uploads. `report` only logs accounts with no storage left; `enforce` sets the quotas, which blocks new uploads at the plan limit and keeps existing files.
