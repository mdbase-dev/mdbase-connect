## Added

- `PropertyList` in `@mdbase-dev/ui/properties` edits values that have parts of their own. A value with named parts is shown part by part under its name and a list of such values one under another by place; either folds away, parts and list items are added from its row, and a list item is named by the first text it holds. `PropertyInfo` gains the `group` kind with `parts` and `rest`, and `items` for what a list holds, and `propertyKind` returns `group` and `items` for these values, which could not be edited before.
- `PropertyInfo` takes `required`, `description` and `link`. A required property always has a row, is marked and cannot be taken off. A property declared with `link` holds one link or several whatever its value looks like, and one declared with the `date-time` format is edited as a date and time in the reader's zone and stored in UTC (`propertyKind` returns `datetime` for it). `PropertyList` takes `errors`, keyed by a value's path such as `steps.0.title`, and shows each under its value.
- `PropertyRecords` takes `resolve`, `link`, `creates` and `create`, for a host that resolves links through its collection, writes them in the collection's form, and makes a record from a property's picker. `search` is also passed the property being filled in, and a record can carry an `icon`.
- `blankValue` gives the value a declared property starts from. A list of numbers stays numbers when it is edited as tags.
- A value that is not what its type says is edited as the type has it, so typing puts it right: text where a number is declared, a number where text is, and one value where a list of short values is. Enter in such a field writes the value as it reads.
