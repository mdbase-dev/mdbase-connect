## Fixed

- In the Editor, Backspace on an empty nested list item lifts it a level instead of leaving its indentation, and Shift+Enter in a list item starts a new line of the same item, lined up with its text, instead of at the start of the line.
- Tab outside a list types a tab and Shift+Tab removes indentation, as Tab and Shift+Tab already did in lists, code and tables. Press Escape, then Tab, to move focus out of the note.
