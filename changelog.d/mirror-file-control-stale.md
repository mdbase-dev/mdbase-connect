## Fixed

- Stop directory mirrors from retrying a refused file upload, move or delete forever. A stale revision, an occupied path, an expired upload or a full storage quota now makes the mirror plan again, so syncing resumes once space is freed. A file over the size limit is set aside at once, and an object the authority keeps definitely refusing (the same 4xx answer at least 10 times over at least an hour) is set aside as a conflict. Server errors, rate limits and connection failures never set anything aside. Other files keep syncing, and a set-aside file stays on disk for the user to resolve.
