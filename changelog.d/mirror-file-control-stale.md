## Fixed

- Stop directory mirrors from retrying a refused file upload, move or delete forever. A stale revision, an occupied path, a file moved or deleted on another device, or an expired upload now makes the mirror plan again. A file over the size limit is set aside at once, and a file the authority keeps refusing outright (the same refusal at least 10 times over at least an hour) is set aside as a conflict. Server errors, rate limits, a full storage quota and connection failures never set anything aside: the mirror retries the same upload, which resumes rather than starting again. Other files keep syncing, and a set-aside file stays on disk for the user to resolve.
