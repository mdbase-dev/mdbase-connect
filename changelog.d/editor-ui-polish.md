## Changed

- Line up the Editor's panes: the rail, note list, note and side panel each open with one bar of the same height, with their rules and icons on one line.
- Show note rows on two lines (title and time, then folder, opening text and type), so about four more notes fit on a screen. A note's type is named once, in one chip that carries the type's icon.
- Mark the selected note with the same inset rounded fill as the rail.
- Give the note list a labelled New button, with the type choice attached to it. The search field now hints `/`, the key that focuses it, and Commands (`Ctrl+K`) has its own row in the rail.
- Show a note's path in the interface typeface with the folder quieter than the file name, and keep the path monospace only while it is being edited.
- Size the note title from the note text size so it outranks headings in the body, narrow the writing column to about eighty characters, and stop Quiet Markdown from scaling headings twice.
- Name the folder tree in the rail and move New folder to its heading. Give Send feedback a bug icon and show a green dot when connected.
- Show bars in place of a loading note, note list and editor instead of a sentence, fade popovers in, and pulse the status dot while reconnecting.
- Move a note's word count, size and modified time to the foot of the Properties panel, and rename the panel's first tab to Fields.
- Drop descriptions from settings whose names already say what they do, and two restating sentences from the type editor.
