## Changed

- Editor: open notes in a new tab with Ctrl/Cmd-click or middle-click in the note list, show the `Alt+T` shortcut hint on "Open in new tab" in the note row menu, and offer "Select" in desktop row menus for non-contiguous selection.
- Editor: add discoverable Split right and Split down controls to the editor pane header and the tab context menu.
- Editor: show full folder paths in tooltips on sidebar rail folders, tighten folder-row spacing, and allow a wider collection rail so common folder names do not aggressively truncate.
- Editor: render a quiet fixed-height placeholder on unloaded note excerpts so note list rows do not shift height when notes are opened.
- Editor & UI: carry the active collection ID in the Editor app switcher links and note in the switcher menu that signing in to the target app may be required to open the collection.
