## Added

- The shared collection UI supports work before connecting. With `unsynced` on `CollectionGate`, `CollectionPanel` or `useCollectionUi`, the signed-out screen offers "Continue without connecting". The app then renders in its unsynced collection with one quiet line, "Saved only in this browser" (or "on this device"), and Connect to sync your work. Once a collection is open, a banner offers to bring the work in. It asks first when names change or types are added, and offers to discard the work after the person confirms. `useUnsyncedSavedLabel()` gives an app's own save notice the same wording. The UI reads the new SDK API structurally, so it still builds against SDK releases without it.
