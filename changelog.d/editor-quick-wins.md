## Added

- Recognise GitHub-flavoured Markdown in the Editor (strikethrough, tables, task lists and autolinks), highlight JSON and YAML code blocks, wrap list items with a hanging indent, and show links to missing notes as missing.
- Turn on spelling correction and sentence capitalisation in Editor prose, and off in paths and names.
- Install the Editor as an app from the browser, with full-bleed and maskable icons.
- Open note context menus with a long press on touch screens, keep inputs from zooming the page on phones, and respect the notch and home indicator.
- Match Editor searches regardless of accents, rank aliases just behind titles, and lift recently opened notes in Quick open.
- Keep recent notes separate for each collection.
- Keep the Editor note list fast to sort in large collections, and apply removed files without reloading the whole file list.
