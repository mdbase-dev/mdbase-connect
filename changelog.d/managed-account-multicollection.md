## Fixed

- Managed hosted account migration now processes every held collection, preserves partial cutover progress and original ambiguous Worker launches, and flips the account once using combined cutover and timer evidence. Transferred history is excluded. The account's single recorded migration start selects the job: an ordinary archived start uses this managed path in LAB, staging and production, while a LAB fixture start keeps its singleton contract; missing, repeated, unknown or cross-environment starts refuse. Live managed multi-collection qualification is pending.
- Transferred hosted history is no longer routed to the hosted migration Worker. An ordinary hosted→local promotion leaves that id as the owner's local collection, so it and any later cloud copy of it use the control plane's own deployments; held collections keep their migration route before and after the flip.
